# University Helpdesk Bot

This project is a University Helpdesk Chatbot built with FastAPI, MongoDB, and a simple HTML frontend.

Features:
- Student chatbot interface
- Admin dashboard with analytics
- MongoDB chat storage
- Menu-based student queries
